# Baseline Car & Dog Wash

Website for Baseline Car & Dog Wash, 39 Base Line Rd W, London, ON.

## Run locally

    npm install
    npm run dev

## Build

    npm run build

Output goes to `dist/` — upload it to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages).

## Files

- `index.html` — page content
- `src/style.css` — fonts, keyframes, hover states
- `src/main.js` — loader, scroll animations, service pop-ups, photo viewer
- `src/services.json` — service pop-up text
- `public/assets/` — logo and photos

Set `MOTION = 'subtle'` or `SHOW_BUBBLES = false` at the top of `src/main.js` to tone down animation.
